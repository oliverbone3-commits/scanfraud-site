Platform

Built-in tools, not bolt-on integrations

Every feature is part of the core platform — not a third-party plugin. From rule construction to device fingerprinting, it all works together.

Visual rule builder
Create and deploy fraud rules without writing code. Combine any transaction attribute — geography, amount, velocity, device — into custom logic. Simulate against historical data before going live.
Real-time dashboard and alerts
Live transaction feed with accurate metrics. Custom alerts and reports. Prompt notifications when thresholds are breached or suspicious patterns emerge.
Device fingerprinting
Embed our fingerprinting script on checkout pages to identify devices. Detect when multiple accounts share the same device, or when a known fraudster returns with new credentials.
Black and white lists
Block known bad actors by email, IP, card BIN, or device. Whitelist verified customers so they aren't caught by broad rules. Manage lists manually or via API.
Link analysis
Detect connections between transactions, accounts, and devices. Find fraud rings by tracing shared parameters across seemingly unrelated events.
Access control
Granular role-based permissions. Control access to specific sections, actions, and merchant data. Full audit trail of every user action in the system.
